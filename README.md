# JustSport

JustSport — це футбольний сайт для перегляду матчів, новин і оновлень сайту. Дані про матчі та новини надходять із зовнішніх API й зберігаються в базі даних.

## Можливості

- Перегляд матчів за датою, лігою та статусом.
- Перегляд новин і фільтрація новин за лігою.
- Реєстрація, вхід і вихід з акаунта.
- Коментарі до новин для авторизованих користувачів.
- Архів новин та оновлень сайту.
- Адміністрування записів через Django Admin.
- Автоматичне отримання даних із API за розкладом.

## Використані технології

- Python
- Django
- SQLite
- HTML і CSS
- Django Templates
- API-Sports для футбольних матчів
- GNews API для новин
